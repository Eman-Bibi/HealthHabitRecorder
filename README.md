# Health Habit Recorder

This is a Java console application for tracking and analyzing health habits. Users can record health data, calculate BMI, monitor blood pressure and blood sugar levels, generate health scores, and save records for future use.

## Features

- Record daily health information
- Calculate BMI (Body Mass Index)
- Monitor blood pressure and blood sugar levels
- Generate health scores
- View and search records
- Analyze health performance
- Save and load records using file handling

## How to Run

1. Open the project in NetBeans or any Java IDE.
2. Compile and run the `HealthHabitRecorder.java` file.
3. Use the menu options to record, view, search, and analyze health data.
